# Prototype Version 2 Overview (Iterated & Refined)
## Smart Cafeteria Ordering Mobile Application

Version 2 represents the refined prototype incorporating design iterations directly driven by usability testing feedback from 5 campus participants.

---

### Major UI Improvements in Version 2

#### 1. Home Dashboard Active Order Card
- Added a high-contrast **Active Order Banner** at the top of the Home Dashboard. Users can see their live order status (*Order #1045 - Preparing - Est. 10 mins*) instantly upon opening the app.

#### 2. Dedicated Collection Time & Venue Selection Screen
- Separated checkout into explicit sequential steps:
  `Cart` ➔ `Collection Time & Venue` ➔ `Payment` ➔ `Confirmation`.
- Added clear visual chips for pickup times (*12:15 PM*, *12:30 PM*, *12:45 PM*) and greyed out unavailable time slots.

#### 3. 1-Tap Express Reordering
- Updated "Reorder" button logic so tapping "Reorder" from Order History or the Home Quick Reorder Tray automatically populates the cart with exact past customizations and navigates straight to checkout.

#### 4. Front-End Error Prevention for Sold-Out Items
- Added explicit red **"Sold Out"** badges directly on meal cards and disabled the item card touch target upfront.

---

### Revised Usability Metrics (V2)
- **Task Completion Rate:** **100%** across all 5 tasks.
- **Average Order Time:** **48 seconds** (43% reduction in time on task).
- **System Usability Scale (SUS) Score:** **86.5 / 100** (+18.0 point increase over V1).
